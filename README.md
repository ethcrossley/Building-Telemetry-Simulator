Building Telemetry Simulator
A Python project that simulates telemetry data from building automation system (BAS) sensors.

This project is being developed as part of my transition from Building Automation Systems and Controls Engineering into software development, IoT, and OT/IT integration.

Current Features
Temperature sensor simulation
Multiple sensor locations
Object-oriented Python design
Git and GitHub version control

Technologies
Python
VS Code
Git
GitHub

Project Goals
The long-term goal is to simulate a realistic building telemetry environment capable of generating sensor data for:

Temperature
Humidity
CO₂
Occupancy
Energy Consumption

Future development will include:
Continuous telemetry generation
CSV data logging
Data analysis with Pandas
REST APIs using FastAPI
MQTT messaging
Cloud integration concepts
